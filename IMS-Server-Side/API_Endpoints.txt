# IMS API Documentation for Postman

**Base URL:** http://localhost:8090/api/v1

---

## 1. Authentication (AuthController)

### Sign Up
- **Method:** POST
- **URL:** {{base_url}}/auth/signup
- **Body (JSON):**
```json
{
  "f_Name": "John",
  "l_Name": "Doe",
  "email": "john.doe@example.com",
  "contactNo": "0771234567",
  "role": "LAB_TO",
  "gender": "MALE",
  "state": true,
  "password": "password123",
  "departmentId": 1
}
```

### Sign In
- **Method:** POST
- **URL:** {{base_url}}/auth/signin
- **Body (JSON):**
```json
{
  "email": "john.doe@example.com",
  "password": "password123"
}
```

## 2. Inventory Items (InventoryItemController)

### Get All Items
- **Method:** GET
- **URL:** {{base_url}}/inventory/all

### Get Items by Department
- **Method:** GET
- **URL:** {{base_url}}/inventory/department/{deptId}

### Get My Department Inventory
- **Method:** GET
- **URL:** {{base_url}}/inventory/my-department

### Get Items by Type
- **Method:** GET
- **URL:** {{base_url}}/inventory/type/{type} (type: CAPITAL | SIMPLE)

### Get Low Stock Items
- **Method:** GET
- **URL:** {{base_url}}/inventory/low-stock

### Add Item
- **Method:** POST
- **URL:** {{base_url}}/inventory/add
- **Body (JSON):**
```json
{
  "name": "Projector",
  "type": "CAPITAL",
  "categoryId": 1,
  "departmentId": 1,
  "specifications": "4K Ultra HD, Wireless",
  "quantity": 5,
  "threshold": 2,
  "location": "Lab 01"
}
```

### Update Item
- **Method:** PUT
- **URL:** {{base_url}}/inventory/update/{id}
- **Body (JSON):**
```json
{
  "name": "Projector Pro",
  "type": "CAPITAL",
  "categoryId": 1,
  "departmentId": 1,
  "specifications": "8K Ultra HD, Wireless",
  "quantity": 5,
  "threshold": 1,
  "location": "Lab 02"
}
```

### Stock In
- **Method:** PUT
- **URL:** {{base_url}}/inventory/stock-in/{id}
- **Body (JSON):**
```json
{
  "quantity": 10
}
```

### Mark Disused
- **Method:** PUT
- **URL:** {{base_url}}/inventory/disuse/{id}

## 3. Inventory Requests (InventoryRequestController)

### Submit Request
- **Method:** POST
- **URL:** {{base_url}}/request/submit
- **Body (JSON):**
```json
{
  "itemName": "Laptop",
  "itemType": "CAPITAL",
  "categoryId": 1,
  "departmentId": 1,
  "quantity": 2,
  "purpose": "For student lab work",
  "specifications": "i7, 16GB RAM, 512GB SSD"
}
```

### Review Request (Lab In-Charge / MA)
- **Method:** PUT
- **URL:** {{base_url}}/request/review/{id}
- **Body (JSON):**
```json
{
  "technicalRemarks": "Specifications verified and approved for purchase.",
  "purchaseDetails": ""
}
```

### HOD Decision
- **Method:** PUT
- **URL:** {{base_url}}/request/hod-decision/{id}?approve=true

### IMO Decision
- **Method:** PUT
- **URL:** {{base_url}}/request/imo-decision/{id}?approve=true

### Record Purchase (MA)
- **Method:** PUT
- **URL:** {{base_url}}/request/purchase/{id}
- **Body (JSON):**
```json
{
  "technicalRemarks": "Purchased from ABC Suppliers",
  "purchaseDetails": "Inv No: 12345, Date: 2024-03-13"
}
```

### My Requests
- **Method:** GET
- **URL:** {{base_url}}/request/my

### Get Requests by Status
- **Method:** GET
- **URL:** {{base_url}}/request/status/{status} (STATUS: PENDING | REVIEWED | HOD_APPROVED | IMO_APPROVED | PURCHASED | REJECTED)

### Get All Requests
- **Method:** GET
- **URL:** {{base_url}}/request/all

### Get Requests by Department
- **Method:** GET
- **URL:** {{base_url}}/request/department/{deptId}

## 4. Maintenance (MaintenanceController)

### Request Maintenance
- **Method:** POST
- **URL:** {{base_url}}/maintenance/request/{itemId}
- **Body (JSON):**
```json
{
  "description": "Screen flickering issue"
}
```

### Approve Maintenance
- **Method:** PUT
- **URL:** {{base_url}}/maintenance/approve/{id}

### Reject Maintenance
- **Method:** PUT
- **URL:** {{base_url}}/maintenance/reject/{id}

### Complete Maintenance
- **Method:** PUT
- **URL:** {{base_url}}/maintenance/complete/{id}
- **Body (JSON):**
```json
{
  "completionNotes": "Replaced the display panel",
  "serviceProvider": "Tech Hub PVT Ltd",
  "cost": 15000.0
}
```

### Get Maintenance by Item
- **Method:** GET
- **URL:** {{base_url}}/maintenance/item/{itemId}

### Get All Maintenance Records
- **Method:** GET
- **URL:** {{base_url}}/maintenance/all

### Get Maintenance by Status
- **Method:** GET
- **URL:** {{base_url}}/maintenance/status/{status} (STATUS: PENDING | APPROVED | IN_SERVICE | COMPLETED | REJECTED)
